# Stock Derby 美股賽馬

用美股股價賽馬：選馬群（S&P 500 / Nasdaq-100 / 兩者合併）與賽程（1/3/6 個月），
看「賽馬報」（近績、跑法、能力）選馬，再回放賽事看誰先衝線。

## 頁面（三個分頁）
- **🏁 賽馬**：預設週期＝季。進入就是**當下最新的賽況**：這一期還在進行，馬群先快跑一遍「期初到今天」，然後持續奔跑（沒有終點線）。可用「週期」選單看前幾期：馬群**停在起跑點**，按「▶ 開跑」跑一次（含終點衝線），或按「⏭ 直接看結果」立刻跳到最後一天的結果。
- **週期可切換**：1天 / 1週 / 2週 / 1個月 / 季 / 半年（日曆對齊：週＝週一到週日、季＝1–3 月等）。每個週期都有「進行中的一期」＋前 5 期。
- **📋 馬報**：每匹馬的近績、跑法、能力；用「週期」選單切換各期的馬報；「🎨 馬匹圖鑑」按鈕展開圖鑑。
- **🎟 下注**：賠率板（獨贏／位置）、投注單（選馬 → 玩法 → 金額）、我的注單（熱感紙風格的票券：票號、條碼、待開獎／中獎／未中印章）。**位置＝押的馬跑進前三名就中**；獨贏＝第 1 名。
- 說明文字預設收合，點 ⓘ 或能力名稱才展開（能力以馬會用語命名，點開才顯示實際參數，例如「爆發力」＝60 日年化波動率）。

## 賽制
- **一期（period）**：日曆對齊的區間；起跑價＝上一期最後一個交易日收盤，終點＝本期最後一個交易日收盤（還原股利與分割）。
- **參賽馬**：上一期漲幅最高的 10 檔（開跑前就已知）。進行中的一期看「截至最新收盤」的排名；結束後依實際漲幅排名。
- **賽道（鏡頭跟拍）**：領先馬固定在右側，其他馬依「落後領先者幾個百分點」排在左邊（開根號壓縮，縮放平滑變化）；地面向後捲動＝全員向前跑，落後的馬只是比領先者慢，不會倒退。**終點線＝期末最後一個交易日收盤**，只在最後 10% 才進場，之後各馬依實際名次、按差距的時間差衝線。手機版自動縮放，10 條賽道在一個畫面內看完。
- **馬號**＝賽前預測名次（1 號＝◎本命）。**近績**＝同週期前 4 期名次；**跑法**＝前 3 期前 1/3 段平均排名（領放/跟前/居中/後上）。
- **能力**：五大關鍵參數在馬群中的百分位（一律越高越好；歷史上負相關者改用反向定義），依週期對應的 IC 加權成「能力指數」。頁面列出權重與回測（樣本內、存活者偏差，僅供參考）。
- **賠率（隨賽況調整、越晚越貴）**：開賽時以評估分（能力 70% ＋ 近績 30%）+ Plackett-Luce 模擬定價；進行中改為「開賽賠率」與「目前排名＋剩餘天數的蒙地卡羅勝率（一因子隨機漫步，波動率取各馬 60 日波動 ×0.85）」的幾何加權，權重＝期間已過比例 u；賠率＝(1−抽水(u))÷機率，抽水(u)＝15%＋25%·u²，範圍 1.05～99。下注當下賠率鎖定。
- **截止下注**：已過 80% 的交易日即截止，實際截止時間是「下一個交易日美東 09:30 開盤」（1 天賽＝開賽日開盤前）。點數是虛擬的，沒有金錢價值，注單存在瀏覽器 localStorage，期末收盤資料出來後下次開啟頁面自動結算。
- 過去 40 季回測：固定賠率押領先馬期望報酬 +128%～+342%，現況定價下約 0～−21%（樣本小，誤差約 ±25 個百分點）。
- 賽馬報只用起跑日**以前**的資料（單元測試檢查因子無前視偏差、未結束的賽事不含結果）。
- **動畫**：路徑平滑後由彈簧阻尼模型追隨（有慣性、加減速），步頻隨速度變化。
- **資料更新**：GitHub Actions 每天固定兩次（UTC 23:30 與 12:30，約美東收盤後 3.5 小時與隔天開盤前），並在上游每日快照跑完時再跑一次。除了讀 repo 的 S&P 500 快照，還會用 yfinance 把所有成分股最近兩週的價格補抓進 `data/recent_prices.csv`（接在快照後面並對齊還原基準），所以不必等上游快照。
- **資料真實性**：數字由 Yahoo Finance 日收盤價與維基百科成分股名單計算；馬名/毛色/靈感說明是創作。

## 馬匹造型
- **目前 app 使用的是像素風素材庫（`assets/horses/`），沒有改變。**
- **實驗中的其他畫風（扁平向量 / 手繪插畫 / 賽博霓虹）另外存放，尚未接進 app**：執行 `python stock-derby/tools/make_sprites.py --styles` 會把它們輸出到 `assets/horses_styles/`（不納入版控，預覽圖見 `assets/horses_styles_preview.png`）。畫風不限於這幾種，之後可以再討論要採用哪些。四種畫風共用同一組奔跑姿勢，只是上色/描繪方式不同。復古卡通風格有版權疑慮，不採用。
- `tools/make_sprites.py` 用程式生成 48×36 像素風精靈圖（6 格奔跑 + 1 格站立，含騎師），輸出到 `assets/horses/`；**不是**圖像生成模型的產物，改程式重跑即可。
- `tools/horse_specs.py` 是 60 檔公司的專屬設計：馬名由公司名轉成有特色的馬名，毛色/鬃毛/花紋/騎師衣色**只參考該公司 logo 的配色與大致樣式**（例如 Microsoft 的四色分區、Amazon 的橘色微笑弧線、NVIDIA 的綠＋眼睛同心圓），沒有複製 logo。
- 沒有專屬設計的股票：依代號雜湊分配 20 種通用毛色之一（同場不重複），馬名為「形容詞＋代號」。
- 想新增公司：在 `SPECS` 加一筆再執行 `python stock-derby/tools/make_sprites.py && python stock-derby/build_derby.py`。
- 圖鑑已併入主頁的 🎨 分頁（`gallery.html` 只做轉址）。

## 五大關鍵參數怎麼來
`factor_study.py` 對 12 個候選指標（技術 7、籌碼 3、財務 2）逐月算與未來 1/3/6 個月報酬的 Rank IC，
負相關者先反向（越高越好），再挑出相關性最強且彼此相關 ≤0.7 的五項，結果寫在 `data/key_factors.json`（含全部 12 項成績）。
**誠實提醒**：IC 都很弱（約 0.01–0.06），名單有存活者偏差；美股無免費法人籌碼資料，
籌碼面用量價資金流向代替（本次未入選）。這是遊戲化的參考，不是預測，也不是投資建議。

## 檔案
- `data_loader.py` 讀價量（repo 的 S&P 500 parquet 快照 + `data/extra_prices.csv`）
- `factors.py` 候選因子　`factor_study.py` 因子研究　`build_derby.py` 產生 `data/derby.json`
- `fetch_extras.py` 補抓不在 S&P 快照內的 Nasdaq-100 成分股；名單每天從維基百科 [List of NASDAQ-100 companies](https://en.wikipedia.org/wiki/List_of_NASDAQ-100_companies) 更新（失敗時依序退回 slickcharts、nasdaq.com、上次快取、`universe.json`，並在頁面標示來源）
- `index.html` 純靜態前端　`.github/workflows/stock_derby_daily.yml` 每日建置＋發佈 Pages

本機：`python stock-derby/build_derby.py && python -m http.server -d stock-derby`
